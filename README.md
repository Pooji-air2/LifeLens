# LifeLens

🌟 LifeLens – Smart Personal Life Assistant

📌 Project Overview

LifeLens is a smart personal assistant web application designed to help users manage their daily activities, track their lifestyle, and improve productivity.

This project focuses on making life easier by organizing tasks, storing useful data, and providing a simple and interactive user interface.

---

🚀 Features

- ✅ Add and manage daily tasks
- ✅ User-friendly interface
- ✅ Data storage using database
- ✅ Fast and responsive design
- ✅ Helps improve productivity

---

🛠️ Technologies Used

- Frontend: HTML, CSS, Bootstrap
- Backend: Python (Flask / FastAPI)
- Database: SQLite / MySQL
- Tools: VS Code, GitHub

---

📂 Project Structure

LifeLens/
│── main.py
│── templates/index.html
│── static/style.css
│── database.db

---

▶️ How to Run the Project

1. Clone the repository
2. Install required libraries
3. Run the app:

python app.py

4. Open browser and go to:

http://127.0.0.1:8000
